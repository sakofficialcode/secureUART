Proposed is a full-custom implementation of a UART transceiver module incorporating a shrinking-generator-based stream cipher with a 32-bit encryption key. The module is designed to be incorporated into hardened MCUs to secure I/O. Keys are loaded through dedicated pins and cleared upon entry into either of the test modes. To test the module, a mux-scan chain will cover all core blocks of the design apart from the encryption blocks: TX & RX shift registers, baud generator, sampling logic, and control logic. A loopback built-in self test will also be used to test the entire datapath including encryption cores.
